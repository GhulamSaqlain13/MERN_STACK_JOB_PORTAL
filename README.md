MERN Stack Job Portal
A fully functional Job Portal application built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. This platform allows users to register as job seekers or recruiters, post and apply for jobs, and manage their profiles.

Features
 Job Seekers
- Register and login
- Browse and search jobs
- Apply to jobs
- View applied jobs
- Update user profile
  
 Recruiters
- Register and login
- Post new job listings
- View list of applicants
- Manage posted jobs
- Update recruiter profile

 Authentication & Security
- JWT-based authentication
- Role-based access control (User / Recruiter )
- Protected routes
- Password hashing

 Admin Panel 
- Manage users and jobs
- Delete spam or inappropriate content


Tech Stack
 Technology | Description 
 MongoDB    | NoSQL database for storing user and job data 
 Express.js | Backend framework for building APIs 
 React.js   | Frontend UI built with React and hooks 
 Node.js    | Runtime environment for backend 
 Mongoose   | ODM for MongoDB 
 Redux Toolkit | State management 
 JWT        | Secure authentication 
 Cloudinary | Image uploads (for profile pictures or company logos) 
 Multer     | File uploads (if applicable)
